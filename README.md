# V-KARE MIND AND BRAIN CLINIC – Premium Website

A modern, minimalist, premium mental healthcare web application designed specifically for **V-KARE Mind and Brain Clinic** (Tumkur, Karnataka).

## 🌿 Design System & Aesthetics
- **Colours**:
  - Forest Green: `#315C49`
  - Sage Green: `#E4EDE5`
  - Cream: `#F7F7F1`
  - White: `#FFFFFF`
  - Warm Beige: `#C6B89F`
  - Dark Charcoal / Text: `#102E28`
- **Typography**:
  - Headings: `Playfair Display` (Serif)
  - Body: `Inter` (Sans-Serif)
- **UI Components**: Rounded 16–24px cards, soft shadows, large breathable whitespace, Lucide React icons, and subtle Framer Motion micro-interactions.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ or v20+)
- npm

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
```

### Preview Build
```bash
npm run preview
```

---

## 🌐 Deployment on Vercel
1. Push this repository to GitHub or run `npx vercel`.
2. Vercel will automatically detect Vite and use `vercel.json` configurations.
3. Build Command: `npm run build`
4. Output Directory: `dist`
